# Code of conduct

Treat everyone with respect in issues, pull requests, reviews, and other project spaces. Welcome questions, give specific and constructive feedback, and focus disagreements on the work. Respect people's privacy and the time contributors volunteer.

Harassment, threats, discriminatory language, personal attacks, sexualized content, spam, and publishing private information without permission are unacceptable.

Maintainers may edit or remove inappropriate content, close disruptive discussions, and restrict participation. Enforcement should consider the severity and context of the behavior.

Report concerns to the maintainer, @lilbuda, through the contact options on their GitHub profile. If a private channel is needed, request one without sharing sensitive details publicly. Maintainers should handle reports discreetly and give affected participants an opportunity to explain when appropriate.
